# 考勤数据管理平台(数据看板)

我与 AI 助手(GoerMate)共用的**考勤/旷工数据分析看板**,托管于 GitHub Pages。

## 🌐 固定访问地址

**https://lily553520.github.io/lily-workspace/**

## 📌 功能模块

- **日出勤表**(首页看板):日期筛选 + 今天快捷键、旷工总人数/旷1~旷6 统计卡片、连续旷工人员明细、各项目旷工分布
- **旷窗口监控**:全部连续旷工区间,按部门/项目/状态/关键字筛选,可导出
- **流失率报表**:月度流失率,单元格可直接编辑,自动算流失率
- **内存报表**:生产计划/实际/达成率,可编辑、导入导出
- **源文件**:AI 助手上传的文件集中管理(原文件工作区功能)

## 🔧 实际可用功能

- **导入Excel**:支持 .xlsx / .xls / .csv,自动识别表头(员工编号/姓名/异常日期/部门/项目/连续旷工天数),自动应用项目映射与 Group 规则,跳过重复行
- **导出明细**:按当前筛选导出 xlsx(本地 SheetJS 组件,无外部依赖)
- **维护Group规则 / 项目匹配关系表**:导入时自动归一化部门归属与项目口径
- **操作日志**:导入/导出/删除/编辑全记录
- 数据保存在浏览器 localStorage;换电脑可用「导出Excel → 再导入」迁移
