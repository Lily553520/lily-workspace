# 我的文件工作区

这是我与 AI 助手(GoerMate)共用的**长期固定文件工作区**,通过 GitHub Pages 托管。

## 🌐 访问地址

**https://lily553520.github.io/lily-workspace/**

## 📌 工作方式

- **AI 自动上传**:对 AI 助手说"导出 xx 文件 / 把 xx 放到工作区",它会自动把文件放入 `files/` 目录、更新 `files.json` 并推送,网页链接永远不变。
- **手动编辑**:也可以在 GitHub 网页上直接编辑(比如修改 `index.html` 的样式、改 `files.json` 里的备注文字)。
- **搜索与分组**:首页支持按文件名/备注搜索,按日期分组展示。

## 📂 目录结构

```
lily-workspace/
├── index.html    # 工作区首页(可自行修改样式)
├── files.json    # 文件清单(AI 维护,也可手动编辑 note 字段)
├── files/        # 上传的文件都存这里
└── README.md     # 本说明
```

## ⚠️ 注意事项

1. **仓库是公开的**:GitHub 免费版 Pages 要求公开仓库,任何知道链接的人都能访问其中的文件。
   - 请勿存放含敏感信息(密码、薪资、客户机密等)的文件;
   - 可将仓库名设置得不易猜测,提高隐蔽性;
   - 如需更强隐私,可升级 GitHub Pro 使用私有仓库,或对敏感文件做加密处理。
2. 文件名建议避免空格和特殊字符(中文文件名可以正常使用)。

## 🔧 常用编辑操作

- 改某条文件的备注:编辑 `files.json` 中对应条目的 `"note"` 字段
- 删除文件:删除 `files/` 下对应文件,并同步删除 `files.json` 里的条目
- 改首页标题/配色:编辑 `index.html` 顶部的 `<title>` 和 CSS 变量(`:root` 部分)
